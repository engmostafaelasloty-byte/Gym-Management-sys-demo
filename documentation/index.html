Ultimate Gym Management System

Documentation v2.0 | Next.js 14 + MongoDB

1. Introduction

Thank you for purchasing the Ultimate Gym Management System.

This is a modern, high-performance web application built with Next.js 14, React, and MongoDB. It natively supports branch isolation (Men, Women, Mixed) with advanced permissions, making it perfect for fitness centers that require strict data separation.

  • Created By: Mostafa Elasloty
  • Platform: Next.js 14 (App Router)
  • Database: MongoDB Minimum v6.0

2. Requirements

Before installing, make sure your server or local environment meets the following requirements:

  • Node.js (v18.0.0 or higher)
  • NPM or Yarn
  • MongoDB (Local installation or MongoDB Atlas Cloud URI)

3. Installation & Setup

Step 1: Extract Files

Extract the downloaded ZIP file to your preferred directory.

Step 2: Install Dependencies

Open your terminal, navigate to the extracted folder, and run:

npm install

Step 3: Database Configuration

Create a file named .env.local in the root directory (where package.json is located) and add your MongoDB connection string:

MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/gym_db

(Or for local MongoDB: MONGODB_URI=mongodb://127.0.0.1:27017/gym)

Step 4: Start Application

Run the development server:

npm run dev

Open your browser and navigate to http://localhost:3000

4. Default Login Credentials

After the first run, the database is ready. Use the following default accounts to log in:

  • Administrator (Full Access): Email: admin@gym.com | Password: admin123 (Mode: Mixed)

Note: You can create custom staff members and assign them strictly to Men's or Women's sections from the settings panel.

5. Core Features Explained

Branch Isolation (Men/Women/Mixed)

Every piece of data (subscribers, attendance, payments, goods) is tagged with a "mode". When a staff member logs in, they can only see and interact with data matching their assigned mode. Admins have access to all data.

Point of Sale (POS) & Inventory

The system includes a fully functional POS that supports barcode scanning. You can add gym goods like supplements, assign barcodes, track stock quantities, and process sales. System warns you when stock is low.

QR Code Attendance

Every subscriber automatically gets a unique QR Code. Staff can scan it from their webcam or barcode scanner to log check-ins. If a subscription is expired, the system denies entry.

6. Deployment to Production (Vercel)

The easiest way to deploy this Next.js app is using Vercel.

  1. Push your code to a GitHub repository.
  2. Log in to Vercel.
  3. Click "Add New Project" and import your repository.
  4. In the "Environment Variables" section, add MONGODB_URI and paste your cluster link.
  5. Click "Deploy".
